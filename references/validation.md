# 版本 1.0.0 验收

执行日期 2026-11-12。覆盖记录见 [阅读清单](reading.md)。185条主张包括书内148条（中国指南62、Duyff译本46、Willett英文书40）、外部核验31条、跨来源应用6条。来源主索引有三本书、27项外部资料和1份应用设计记录；另保留各章核查链接。13套自拟组合与61条英文原食谱定位分存。

| 可复验项目 | 已观察到的结果 |
|---|---|
| 工作日一周菜单 | [七天三餐样例](../tests/field-cases.md)每天合计16–18分钟（含等待），需要能买到熟主食、即食蛋白质与净菜。按虚构单价、包装与配送合计370/380元。脚本重算每日时间与费用，另检查七顿自制晚饭的净用料合并、双人缩放。 |
| 无厨房酒店 | 五天十五餐按含早餐、无冰箱的场景设计，机场、高铁、便利店与点餐均有替代；测试餐费合计254元，逐日均不超过设定上限60元。 |
| 共同备孕 | 分角色解释叶酸。另以甲牛奶蛋白过敏、乙大豆过敏重放共餐检查，豆腐对乙被拦，无乳糖奶对甲被拦。一个成员的禁忌未扩写到另一份个人档案。 |
| 年龄或阶段变化 | 备孕改孕早期使原方案转为待核。老年及围绝经期另有可检索条目。空白与陈旧账户字段未被当作已确认。 |
| 原书冲突 | 奶类、脂肪、饮酒、旧式补充剂建议可沿关系查回两书及对应机构。叶酸异常数字、旧书生禽冲洗与乳糖误称均不进入执行候选。 |
| 无依据的助孕胶囊 | 输出缺乏特定产品临床结局与安全依据，要求核实配方与用药；不选剂量，继续提供可共享的平衡餐。 |
| 信息不清与缺数 | 扫描位置与不宜执行的数据分列。真实燕麦产品标签演算能区分钠标示零和维生素C未知。未知油盐、饮料、调味料会阻止全餐精确总量；单位、生熟不匹配的计算被拒绝。 |
| 临时替换 | 比较饮品的实际体积、钙与蛋白；包含或可能交叉接触已知过敏原时排除。新配料、厨房核实不全时输出待核。 |
| 来源与维护 | 791个PDF物理页和29个EPUB阅读单元均有索引；核对两本PDF主张的页记录及英文书101条主张/食谱段落。新主张通过 supersedes 取代旧版本后，旧值退出方案候选；受影响的应用和菜单须重新评估。 |
| 平台格式与分享边界 | 已通过 Codex 自带技能格式校验。模板为空；样例人物为虚构，包内没有输入PDF、EPUB、OCR全文或任何真实个人档案。 |

安装或移到其他机器后可复测（在技能目录运行）：

```sh
python3 scripts/graph.py validate
python3 -B tests/verify.py
python3 scripts/graph.py conflicts 奶
python3 scripts/kitchen.py nutrients assets/nutrition-input.json
```

10组自动化回归测试与8个场景走查用途不同。自动测试校验引用、逻辑、算术和异常处理，无法验证某家餐馆的过敏工艺、真实厨房耗时、真实采购价格，也不能保证任一人的营养充分性或临床效果。复制或改变食谱后，须按新的食材、可食部、份量与成员条件重算。
